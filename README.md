# 进气空调 (AHU) 设计计算系统

涡轮增压器测试台精密进气空调设计计算器

## 功能

- **参数计算** — 基于湿空气热力学公式（Magnus/GB/T 35226-2017）计算制冷量、加热量、除湿量
- **焓湿图** — 可视化空气处理过程线（h-d 图）
- **设备选型建议** — 基于计算结果推荐表冷器、加热器、风机等设备配置
- **工程制图导出** — 标准 GB/T 图框格式的工艺流程图导出（SVG/PNG）
- **设计指南** — 从零到精通的分步教程
- **知识库** — 核心知识点汇总
- **Excel 报告** — 导出完整设计计算报告

## 技术栈

- **框架**: Electron
- **语言**: 原生 JavaScript (Vanilla JS)
- **制图**: SVG (工程制图标准 GB/T 14689-2008)
- **打包**: electron-builder
- **依赖**: xlsx (Excel 导出)

## 快速开始

```bash
# 安装依赖
npm install

# 启动开发模式
npm start

# 打包
npm run build
```

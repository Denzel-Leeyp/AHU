📖 参数符号及物理意义对照表
符号含义单位说明
🌡 空气状态参数
t / tg干球温度℃普通温度计测得的空气实际温度
tₛ / ts湿球温度℃湿纱布包裹温度计在充分通风下的稳定温度，反映空气冷却极限
t_dp露点温度℃空气中水蒸气开始凝结的温度。三温关系：tg ≥ tₛ ≥ t_dp
RH相对湿度%空气中水汽分压力与同温下饱和水汽压之比
P_sat饱和水汽压kPa一定温度下空气中能容纳的最大水蒸气分压力（Magnus/Sonntag公式）
P_v水蒸气分压力kPa空气中实际水蒸气产生的压力，P_v = RH × P_sat
W / d含湿量kg/kg每千克干空气所含的水蒸气质量，W = 0.622·P_v/(P_atm-P_v)
h / i比焓kJ/kg单位质量干空气的总热量 = 1.006t + W(2501+1.86t)
ρ湿空气密度kg/m³考虑湿度修正的密度，ρ = P/(R·T_v)
P_atm大气压力kPa标准大气压 101.325 kPa
⚡ 负荷参数
Q_c制冷量kW空气处理所需冷量 Q_c = ṁ·(h₁-h₂)
Q_h加热量kW显热加热量 Q_h = ṁ·c_p·(t₂-t₁)
Q_reheat再热量kW盘管出口到目标温度的加热量
dw除湿量/加湿量g/s进出口含湿量差 ṁ·(W₁-W₂) >0 为除湿，<0 为加湿
ṃ质量流量kg/s干空气质量流量
ṁ_chw冷冻水流量kg/s所需冷冻水流量 = Q_coil / (c_pw·Δt)
❄ 表冷器/盘管参数
ε接触系数—ε = 1−(tg₂−ts₂)/(tg₁−ts₁)，反映盘管与空气的接触完善程度
BF旁通系数—BF = 1−ε，未经处理的空气比例
ξ析湿系数—ξ = (h₁−h₂)/[c_p·(t₁−t₂)]，总换热量与显热之比，>1为湿工况
K传热系数W/m²K盘管总传热系数，由迎面风速、排数、析湿系数决定
T_coil盘管出口温度℃空气经盘管处理后的温度（再热前）
LMTD对数平均温差℃ΔT₁−ΔT₂ / ln(ΔT₁/ΔT₂)，逆流换热的平均驱动力
Δh_m对数平均焓差kJ/kg湿工况换热驱动力，替代LMTD用于潜热为主的换热
v_y迎面风速m/s空气进入盘管截面的流速，推荐 2.0~2.5 m/s
v_w管内流速m/s冷冻水在盘管内的流速，推荐 1.0~2.0 m/s
🏗 结构尺寸参数
Q_v体积流量m³/h处理风量 Q_v = ṁ/ρ × 3600
A_face迎面面积m²表冷器截面积，A_face = Q_v / v_y
λ宽高比—箱体宽度与高度之比，推荐 1.5
rows盘管排数排气流方向的铜管排数，2~8排
Δt_chw冷冻水温差℃供回水温差，常用 5℃
🔢 物理常数
c_p空气定压比热kJ/(kg·K)干空气定压比热容 = 1.006
c_pw水定压比热kJ/(kg·K)水的定压比热容 = 4.187
r₀0℃汽化潜热kJ/kg0℃水的蒸发潜热 = 2501
R空气气体常数kJ/(kg·K)干空气气体常数 = 0.287
M_w/M_a分子量比—水/干空气分子量比 = 18.02/28.97 = 0.622
ℓ₀0℃热力学温度K0℃ = 273.15 K
